# 帳本管理系統

一套面向「會員任務 + 採購流水 + 多級分傭」場景的管理系統。

**會員端**是行動端 H5（Vue 2 + vue-router，hash 路由，依手機螢幕 750rpx 適配），**管理後台**是 Laravel Blade 伺服器端渲染，兩者共用同一套 Laravel 應用程式與資料庫。預設使用 SQLite，複製下來跑兩條指令就能用。

---

## 功能一覽

### 會員端（H5）

| 模組 | 說明 |
| --- | --- |
| 登入 | 帳號密碼登入，註冊入口 |
| 首頁 | 店鋪資訊、輪播圖、導覽宮格、公告欄、今日任務 |
| 採購清單 | 依狀態分頁（待付款 / 待確認 / 已確認 / 已完成），只顯示分配給自己的任務 |
| 訂單詳情 | 檢視買賣雙方、任務金額、依序號陳列的收款碼（序號 1 為預設優選），上傳付款憑證 |
| 團隊採購 | 直推 / 間推下線的下單與收益統計 |
| 我的 | 訂單收益、直推收益、可提現餘額；頭像暱稱修改、收貨地址、修改密碼、登出 |
| 明細 | 收益明細、餘額明細、提現紀錄，支援分頁載入 |

### 管理後台

| 模組 | 說明 |
| --- | --- |
| 資料概覽 | 會員數、任務數、資金流向、待處理事項 |
| 使用者資料 | 全欄位可查可改；新增使用者、啟用停用、刪除、餘額調整、批次清空 |
| 採購清單 | 發布任務：先選賣方（含智慧推薦）→ 填任務額度 → 選買方 |
| 採購紀錄 | 檢視使用者上傳的付款憑證，手動確認到帳 / 取消到帳（自動發放各層級獎勵） |
| 資金明細 | 全部流水，可依會員、類型、日期篩選 |
| 提現審核 | 通過 / 駁回提現申請 |
| 系統設定 | 店鋪名稱、輪播圖、導覽宮格、公告、任務收益率、自助註冊開關 |
| 操作日誌 | 所有後台操作的行為軌跡紀錄 |
| 管理員帳號 | 最多 5 個；分為超級管理員與一般管理員 |

**權限分級**：一般管理員登入後只能給使用者安排任務（採購清單 / 採購紀錄）；使用者資料、資金、提現、設定、日誌等僅超級管理員可見。

## 核心業務規則

任務回款 = 本金 + 本人收益，本人收益 = 本金 × 收益率。

- **收益率可設定**：全域預設 1.5%（後台可改 1%～100%），也可給單一會員設定專屬收益率；
- **直推獎勵**：下線參與任務時，其直推人獲得 0.5%（計入餘額）；
- **店長收益**：所屬店長獲得 1.5%；
- **平台留存**：0.5%。

> 收益口徑：會員「訂單收益」只統計本人參與任務產生的收益累計（不含本金）；「餘額」只統計直推下線參與帶來的獎勵，可用於提現。

## 技術棧

| 層 | 選型 |
| --- | --- |
| 後端 | PHP 8.1+ / Laravel 10 |
| 資料庫 | SQLite（預設，開箱即用）/ 可切換 MySQL |
| 會員端 | Vue 2.7 + vue-router 3（Hash 路由）+ 自研 uView 風格元件，無建置步驟，直接引用本地檔案 |
| 管理後台 | Laravel Blade + 原生 CSS / JS，無前端建置 |
| 驗證 | 會員端 JWT（HS256）；管理後台 Session + 圖形驗證碼 |

## 快速開始

```bash
# 1. 安裝相依套件
composer install

# 2. 準備環境變數
cp .env.example .env
php artisan key:generate

# 3. 初始化資料庫（建表 + 寫入管理員與站台設定，不含任何業務資料）
touch database/database.sqlite
php artisan migrate --seed

# 4. 啟動
php artisan serve --port=9193
```

開啟 <http://localhost:9193/> 即為會員端。

需要產生一批示範資料（會員 / 任務 / 收益）時：

```bash
php artisan db:seed --class=DemoSeeder
```

> 上線前請務必在「帳號設定」裡修改密碼，並在 `.env` 中更換 `APP_KEY` 與 `JWT_SECRET`。

## 目錄結構

```
app/
  Http/Controllers/Admin/   後台控制器（使用者、任務、紀錄、資金、提現、設定…）
  Http/Controllers/Api/     會員端 API（登入、首頁、會員、檔案上傳）
  Http/Middleware/          AdminAuth / SuperAdmin / ApiAuth
  Models/                   Member、Order、Balance、Cash、Cert、Address、Setting、Admin
  Services/FlowService.php  任務結算與分傭核心邏輯
config/flow.php             業務參數（服務費、各層級分傭比例、明細類型）
database/migrations/        資料表結構
database/seeders/           初始化資料與示範資料
public/static/              會員端前端資源（JS / CSS / 圖片 / 字型）
resources/views/admin/      後台頁面樣板
routes/admin.php            後台路由
routes/api.php              會員端 API 路由
```

---

## 說明

- 會員端前端不依賴建置工具，改完 `public/static/js/*.js` 重新整理即可生效；
- 後台所有新增、修改、刪除都會寫入 `admin_logs`，可在「操作日誌」中追溯；
- 圖片上傳走 `/app/File/upload`，檔案存放在 `public/uploads/年月/`，限制 8MB，支援 png / jpg / gif / webp。
